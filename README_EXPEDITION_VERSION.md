# CDDA: Zone Expeditions - S.T.A.L.K.E.R. Inspired Overhaul v2.0

**Nouvelle Version Expédition** - Inspirée par le système Innawood pour une expérience plus authentique !

## 🎯 **Revolution Conceptuelle**

Cette version transforme complètement l'approche du mod. Au lieu de convertir tout CDDA en Zone, nous créons un **système d'expéditions temporaires** qui capture l'essence authentique de S.T.A.L.K.E.R. : des incursions dangereuses et limitées dans le temps dans un territoire hostile.

### **🏠 Hub Sécurisé + ⚡ Expéditions Dangereuses**

- **Poste de Contrôle du Cordon** : Votre base sécurisée avec traders, ateliers, et planification
- **Expéditions Temporaires** : Missions de 4-8 heures dans la Zone avec retour obligatoire
- **Tension Temporelle** : Émissions périodiques forcent le retour ou causent la mort
- **Progression Basée Réputation** : Débloquez zones plus dangereuses et équipement avancé

## 🕐 **Mécaniques de Pression Temporelle**

### **Système d'Émissions (Remplace les Zombies)**
```
Phases d'Émission :
┌─ Pré-Émission (15 min) ─ Warning, dysfonctions électroniques
├─ Émission (2-5 min) ──── Dégâts mortels si pas à l'abri  
└─ Post-Émission (30 min) ─ Nouveaux artefacts, anomalies déplacées
```

**Cycle Imprévisible** : Émissions toutes les 1-3 heures créent tension constante
**Abris Obligatoires** : Bâtiments, sous-sols, bunkers = survie
**Conséquences Fatales** : Être pris dehors = mort quasi-certaine

### **Timers Multiples Croisés**
- ⏰ **Timer d'Expédition** : 4-8h avant retour forcé
- ⚡ **Timer d'Émission** : Cycle imprévisible mortel
- 🔧 **Dégradation d'Équipement** : Détecteurs tombent en panne
- ☢️ **Radiation Cumulative** : Empoisonnement progressif

## 🎪 **Gameplay Loop Complet**

### **1. Planification (Hub Sécurisé)**
```
┌─ Choisir Mission ────────── Artefact spécifique / Zone à explorer
├─ Sélectionner Équipement ─ Détecteur, combinaison, médicaments  
├─ Évaluer Risques ───────── Prévisions émissions, menaces connues
└─ Acquérir Permis ───────── Autorisation checkpoint obligatoire
```

### **2. Déploiement**
- **Transport vers Zone** d'opération sélectionnée
- **Activation Timer** d'expédition (4-8 heures)
- **Zone Assignment** : Outer/Industrial/Deep selon réputation

### **3. Exploration Active** 
- **Navigation Anomalies** avec détecteurs
- **Collecte Artefacts** dans champs dangereux
- **Évitement/Combat Mutants** selon stratégie
- **Surveillance Émissions** constante

### **4. Gestion de Crise**
- **Abris d'Urgence** pendant émissions
- **Réparations d'Équipement** en field conditions
- **Soins Médicaux** radiation/blessures
- **Décisions Risk/Reward** : continuer vs retour

### **5. Extraction**
- **Retour Checkpoint** avant deadline
- **Extraction d'Urgence** (coûteuse en réputation)
- **Évacuation Forcée** si timer expira

### **6. Débrief & Progression**
- **Vente Artefacts** aux traders spécialisés
- **Réparation Équipement** endommagé par Zone
- **Gain Réputation** selon succès mission
- **Unlock Nouveau Contenu** zones/équipement/missions

## 🗺️ **Système de Zones Progressives**

### **Zone Externe (Réputation: Rookie)**
- **Danger** : Faible - Anomalies éparses, mutants basiques
- **Rewards** : Artefacts communs (Droplets, Stone Blood)
- **Durée** : 4-6 heures d'expédition safe
- **Objectifs** : Apprentissage, équipement basique

### **Zone Industrielle (Réputation: Experienced)** 
- **Danger** : Modéré - Champs d'anomalies, mutants avancés
- **Rewards** : Artefacts intermédiaires (Fireball, Bubble)
- **Durée** : 6 heures avec risques accrus
- **Objectifs** : Contrats d'escorte, élimination mutants

### **Zone Profonde (Réputation: Veteran)**
- **Danger** : Élevé - Anomalies denses, boss mutants
- **Rewards** : Artefacts rares (Moonlight, Soul)
- **Durée** : 8 heures maximum survie
- **Objectifs** : Reconnaissance deep, récupération équipement expérimental

### **Cœur de Zone (Réputation: Master)**
- **Danger** : Extrême - Réalité déformée, Monolithe
- **Rewards** : Artefacts légendaires (Goldfish, Hypercube)
- **Durée** : Missions spéciales uniquement
- **Objectifs** : Quêtes narratives, secrets du Zone

## 🎯 **Pourquoi Cette Approche ?**

L'inspiration d'Innawood résout les problèmes majeurs de l'approche "total conversion" :

✅ **Tension Authentique** : Chaque expédition est un événement à enjeux élevés  
✅ **Pacing Optimal** : Sessions courtes et intenses vs exploration diluée  
✅ **Progression Significative** : Chaque retour réussi = accomplissement réel  
✅ **Risk/Reward Équilibré** : Décisions critiques avec conséquences majeures  
✅ **Rejouabilité Élevée** : Différentes approches, zones, objectifs  
✅ **Fidélité S.T.A.L.K.E.R.** : Capture l'esprit exact des jeux originaux  

Cette version transforme CDDA en véritable **simulateur d'expéditions Zone** plutôt qu'en simple reskin thématique.
